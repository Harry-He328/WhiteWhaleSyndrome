# 航行体验试调 · 第一轮

目的：保留当前船与桌面的大小比例，先比较较慢的移动、转向和较平缓的海浪。

只修改 Ocean 场景中的 ShipMovement / OceanSurface 参数与现有敌船预制体的运动参数；没有改变船、桌面、碰撞体、镜头或桌面跟随方式。

玩家船：最高航速 7 → 3.5；加速度 6 → 1.2；减速度 6 → 1.8；最大转向角速度 45 → 22.5 度/秒。

敌船：移动速度 4 → 2；转向角速度 90 → 45 度/秒。

海浪：基准振幅 0.48 → 0.32；波长 12 → 18；速度系数 0.48 → 0.35。既有风变化和着色材质保持原配置。

新参数下，全帆约两秒走一个船身，从静止到满帆目标速度约 2.9 秒，收帆停止约 1.9 秒，满帆满舵转半圈约 8 秒。网子速度倍率仍为 0.5。火炮、炮弹、血量和攻击间隔保持原配置。

此前 Captures 中以 7 / 3.5 玩家速度、4 / 2 敌人速度为预期的数值验证记录对应旧参数；本轮不据此重新判断功能失败。

试玩重点：船是否仍然显得急促；转舵后是否容易预判；离开桌面拿物件是否更从容；海浪是否更容易衬托船；较慢移动是否使航行等待过长。
