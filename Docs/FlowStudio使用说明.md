# Flow Studio 事件编辑器

本版是专用流程制作工具。独立场景中只有 UI，不加载房间、海洋、船或敌人。

## 打开

打开 `Assets/Scenes/FlowStudio.unity`，点击 Unity 的 Play，再切换到 Game 窗口。

也可以从菜单 **White Whale → Flow Studio → 打开事件编辑器** 打开该场景。

上一版 `TabletopFlowPrototype.unity` 是海洋演示，相关菜单已移至“旧原型”，不是本工具的入口。

## 编排操作

点 **＋ 新建事件**，在右侧的「下一步」下选择「添加第一步」。通过「下一步」插入新节点或连接已有节点。选中画布上的节点即可修改设置。

- 左侧节点库：拖动到画布创建节点，也可点击添加到画布中间。
- 左侧搜索框：按节点名称或类别筛选节点库。
- 拖动节点标题：移动节点；多个节点选中时一起移动。
- Shift / Ctrl 点击：添加或取消单个节点的选择；空白处左键拖动可框选，Shift 框选追加选择。
- 拖动右侧出口到其他节点左侧入口：创建连线。也支持先点击出口，再点击入口。
- 同一出口再次连接：替换原来的连接。
- 点击节点，在右侧编辑参数。节点名称按类型固定，面板最下方的「备注」支持填写多行文字。备注随流程保存，旧节点的自定义标题会移入备注。
- 点击连线：选中连线，再按 Delete 或点“断开连线”。
- 中键或右键拖动画布：平移；右键单击节点或空白画布：打开相应菜单。
- 滚轮：以鼠标位置为中心缩放。“适应画布”可显示全部节点。
- 节点标题右侧“×”：直接删除该节点；画布上方的“删除选中”批量删除选中节点或断开选中连线。
- Delete：删除选中的节点及其连线。删除、移动和连线变更均可撤销，输入文字时不会触发节点删除。
- Ctrl+A：选择全部节点。
- Ctrl+C / Ctrl+V：复制、粘贴选中节点，保留组内连线，重新生成节点编号。可在同一次工具运行中跨文件粘贴，自动跳过不适合目标流程类型的节点；开始节点保持唯一。
- Ctrl+D：直接创建选中节点的副本，保留组内连线。
- 多选后，右侧提供左对齐、顶端对齐和批量操作。
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y：撤销与重做。
- Ctrl+S：保存；输入框中的待提交内容会先提交。
- Esc：取消连线或关闭弹窗。

「流程模拟」默认收起，开始模拟时自动展开，停止后收起。

工作台运行时允许后台刷新；离开工作台时恢复原设置，不改变项目的 Player Settings。

## 整体流程与事件

**整体流程**负责桌面挑战的阶段与事件顺序。使用“执行事件”节点引用事件文件，并连接“事件完成”和“事件失败”两个出口。

**事件流程**负责具体内容。可以生成或移动物件、等待玩家靠近或拾取、显示提示、让玩家选择，以及接入已配置的玩法。

在「执行事件」节点选择事件后，可点「打开事件」。通过「执行玩法」选择玩法并连接成功、失败分支。节点会显示所选玩法需要的设置。

「触发事件」用于记录希望触发的玩家操作和对应事件。填写的操作文字供策划查阅。

顶部“游戏入口”打开项目当前入口。用工具栏的“打开”切换到其他流程。有未保存修改时，工作台提供保存、放弃或取消。

示例文件：

- `Assets/StreamingAssets/Flows/tabletop_main.flow.json`：桌面挑战第一章，调用猴子岛事件，按结果结束。
- `Assets/Resources/FlowEvents/monkey_island.event`：航行遇岛、摆放三只猴子、船进入靠近区域、对话、猴子进入房间和四波海战。

## 选物件、位置和范围

- **生成物件**设置「物件」和「放置位置」。支持搜索、位置预览和位置偏移。
- **等待移动距离**累计玩家船的移动距离，从到达节点时开始计数。
- **等待靠近**等待玩家船进入指定距离。靠近目标来自此节点之前已生成的物件，所有到达这里的路线都必须先生成它。
- **等待进入范围**等待玩家船到达指定范围。使用生成物件时，把「生成物件」右侧紫色的「生成结果」拖到「等待进入范围」左侧紫色的「范围中心」，然后填写半径。执行顺序仍由「继续」连线设置。也可以选择固定的场景位置作为中心。
- **等待玩家操作**可指定拾取对象。触发后，后续节点可引用「玩家拾取的物件」。
- **显示提示**会在游戏里展示「提示内容」，玩家按 Enter 继续。**玩家选择**会显示两个选项，玩家按 1 或 2 选择分支。

- 给场景对象挂 Flow Scene Bindings，工作台从配置的场景读取对象。生成节点的结果也能被后续节点引用。
- 生成、移动和范围中心都以所选对象的位置为基准。需要偏移时，使用节点里的「调整位置」。
- 「生成物件」支持直接选择物件或使用事件中的共享物件。
- 需要在事件文件上调整某项设置时，在节点右侧展开「更多设置」，选择要公开的项目。

## 保存与加载

“保存”写入当前文件；新流程首次保存时输入文件名。“另存为”另建文件，覆盖其他文件前会确认。“打开”列出文件目录中的整体流程与事件流程。

整体流程存放在 `Assets/StreamingAssets/Flows`。事件资产存放在 `Assets/Resources/FlowEvents`，包含事件节点、公开参数和资源引用。海战波次在战斗配置资产中编辑。

可以保存草稿。「检查」列出需要修正的问题，选择问题可定位对应节点。补齐内容和连线后即可模拟。

这是制作文件，不是玩家存档。它不包含已完成事件或玩家当前进度。

## 流程模拟

点「开始模拟」，当前节点以金色高亮，已执行的节点以绿色标记。右侧显示提示、选项和模拟记录。

等待节点通过按钮提供外部条件：

- 等待靠近或进入范围，分别点「满足距离条件」或「进入范围」。
- 提示和玩家选择，点「确认提示」或对应选项。
- 等待时间：按秒推进，也可跳过。
- 执行玩法，选择「玩法成功」或「玩法失败」。

支持暂停、继续与单步。停止后清除模拟数据，回到编辑状态。

模拟整体流程时，画布自动进入被调用事件，事件结束后返回上层。模拟使用独立数据快照；期间禁止编辑和保存，不会修改制作文件，也不会实际生成物件或启动海战。

## 文件与游戏运行器

JSON v1 包含文档编号、类型、入口、节点、连线与画布布局。节点类型和端口使用固定字符串，不保存 Unity 场景引用或程序集类型名。

`FlowSession` 同时用于工作台模拟和主场景。工作台由按钮提供外部条件，主场景使用真实的船、房间落点和海战系统。完整实景验证从 `MainScene` 开始。

本版面向 Windows 桌面。编辑器使用项目内的文件目录；若构建独立工具，则首次将打包文件复制到 `Application.persistentDataPath/Flows` 供继续编辑，不覆盖已有本地文件。

## 当前边界

流程支持分支、汇合及事件调用。主场景使用 Enter 推进等待确认节点。此次项目中的猴子岛已迁移，手头的旧版专用事件文件需要按新节点重新绑定后才能运行。

## 验证

- `FlowStudioSetup.Verify`：文件往返、覆盖保存、校验、两层调用、胜负与非战斗路径、等待、生成、撤销与运行快照。
- `FlowStudioInteractionVerification.Begin`：在运行场景中向真实 UI 控件发送指针和键盘事件，检查参数、拖动、连线、删除、平移、缩放与模拟按钮。
- `FlowStudioFrontendVerification.Begin`：使用独立临时文件检查节点“×”、固定操作栏删除、批量编辑、框选、成组拖动、复制连线、搜索、右键菜单、输入保护与面板折叠，不改写用户流程。

结果输出到 `Captures/FlowStudioVerification.txt`、`Captures/FlowStudioInteractionVerification.txt` 和 `Captures/FlowStudioFrontendVerification.txt`。
