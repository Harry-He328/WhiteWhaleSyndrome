# 船只战斗实现

运行原有 Assets/Scenes/SampleScene.unity，房间沿用原有 Ocean 附加加载结构。额外创建的 BattlePrototype 场景与其生成器已撤除。

RoomBattleConnection 等待 OceanRoomBridge 连接现有玩家船后初始化 BattleController。玩家船和敌船分别具有 Health、MovementSpeedModifier；敌船复用船资产并使用红色材质，按接近、侧舷对准、开炮和等待的顺序行动，详见敌船AI开发说明。

玩家 100 血、敌船 60 血；沿用原火炮和炮弹，普通命中伤害 10。F5 重试战斗，F6 切换敌船开炮。原房间物件不由战斗创建或补充。胜负结算后停止交战。

核心代码为 Health、BattleDefinition、BattleController、EnemyActor 和 RoomBattleConnection；BattlePrototypeUI 为当前临时状态显示。后续流程可接入 BattleController 的开始与结果接口。
