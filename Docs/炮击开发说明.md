# 船只炮击：第一步

## 当前行为

- 场景已关闭开局试射；玩家拉动桌面火炮背部的拉绳，触发对应船上火炮。
- 炮口位于船模型下的 CannonMounts，跟随船移动。空物体的位置为发射起点，本地 Z 正向为基础射向。
- 当前安装顺序为 LeftMiddle、RightMiddle、LeftFront、RightFront、LeftRear、RightRear。
- 炮弹按低仰角抛物线运动，忽略发射船的碰撞体；命中 Table 标签碰撞体或其他实体时处理一次命中并移除。未命中时最多存续 8 秒。

## 集中调整位置

- 船模型的 ShipArtillery / Installation Order：拖动重排炮位安装顺序；列表长度决定容量，目前六门。
- ShipArtillery / Initial Cannon Count：初始火炮数量，目前两门。
- ShipArtillery / Fire On Start：是否运行开始时试射一次；目前关闭，保留此调试开关。
- Assets/Settings/Combat/StandardCannon.asset：共享的炮弹预制体、初速度、仰角与冷却。目前为速度 3.5、仰角 5 度、冷却 1 秒。
- 每个炮口上的 Cannon / Definition：可以引用不同配置；共享配置不会共享火炮冷却状态。
- Assets/Prefabs/Combat/Cannonball.prefab：Tabletop Tag 为 Table；可调整最大存续时间和普通伤害数值。

## 后续扩展入口

- ShipArtillery.TryAddCannon 按列表顺序安装下一门；满员返回 false。CannonAdded 事件提供新增的独立 Cannon 实例。
- InstalledCannons 供后续桌面模型读取现有火炮；桌面模型各自绑定对应的 Cannon，调用 TryFire。
- ProjectileAttack 为炮弹攻击效果入口，可另写脚本实现 OnImpact，或在 OnLaunched 中初始化特殊行为，并挂到炮弹预制体上。具体效果不写进火炮的发射逻辑。
- DamageOnImpact 为普通伤害实现。受伤对象通过 IDamageable.TakeDamage 接入；桌面命中不造成普通伤害。

## 验证

已通过 Unity 运行验证：初始两发、左右射向、独立冷却、逐门添加与六门上限、Table 命中销毁、一次普通伤害结算、自船碰撞排除、重力弹道与超时销毁。

## 桌面火炮位置管理（已实现，输入待接入）

- 场景位置：Table / TabletopArtillery。
- Display Slots 集中维护六组“船上 Cannon、桌面 Anchor、已有 Model”的明确对应关系。
- Position_LeftMiddle、Position_RightMiddle 等空物体决定桌面模型的位置与朝向，可直接在场景中移动或旋转；船上的安装顺序仍只在 ShipArtillery 中调整。
- 初始两个位置放有预览模型。运行时复用这两个模型，新增火炮时按对应位置生成外观，不重复生成。
- 模型的 TabletopCannon.BoundCannon 指向具体的船上火炮，供下一步击发绳输入使用。本步没有接入玩家输入。
- 位置管理器暂时停用期间新增火炮，重新启用后会补齐模型；重复同步不会增加模型数量。
- 已通过 Unity 运行验证：初始两门、增加到六门、一一绑定、重复同步不重复生成、停用后恢复同步、锚点位移与旋转跟随、模型缺失后重建。

## 击发绳输入（已接入）

- 空手时，对准炮尾拉环附近，按住左键向炮尾后方拖动，允许斜拉。操作期间沿用视角和移动锁定。
- PullRing 上的 CannonPullHandle 将炮尾方向映射到当前视角，只计算向后方向的净拖动位移，默认达到 60 像素尝试开火。
- 每次按住只尝试一次；冷却中触发不会排队或按住后自动补射，松手后可重新拉动。
- Trigger 范围为 0.55 × 0.55 × 0.45；只在拉环附近启动，炮身不触发。墙壁等实体仍参与遮挡判定。
- 松手、Esc、窗口失焦或超出交互距离会清除拖动进度。新增加的桌面火炮从预制体自动继承拉绳输入。
- 目前没有拉环位移、绳子形变或炮身后坐动作。不同装置的最终灵敏度和整体比例 UX 调整仍按开发待办另行处理。
